# Prompt Image Generator

User will upload prompt txt file. Each prompt has been given number. According prompt generate images for all prompt. Give image title/name prompt number. If images generated from prompt 65 then give image name 065.jpg. generate all images for each prompt. Add all images in one zip file and allow user download zip file. Make sure each job save in history and allow any user anytime download complete zip file. No authentication needed
Make sure each txt file contains about 400 to 500 prompts. Also .jpg or .jpeg is not necessary .png is also acceptable. I don't care of resolution but make sure ratio must 16:9 landscape. Make sure it must be fast images generation.
